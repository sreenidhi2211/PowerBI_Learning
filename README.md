# Power BI Learning 

## About This Repository

This repository documents a  Power BI learning journey from scratch to advanced level.

Each module contains a short conceptual summary and references detailed personal notes. 

The repository is structured to serve as both a learning record and a reference guide for future use.

*******

**Learning Approach**

•	Structured module-by-module progression

•	Concept explanation → Real-world analogy → Hands-on implementation

•	Project-based learning using the Superstore Sales dataset throughout

•	Mistakes and corrections documented honestly for deeper understanding from Module 3

**Dataset Used**: Superstore Sales (Single Excel Workbook source — Orders, Returns, People sheets coverted to tables using (Ctrl+T))
