# Phase 1 — Getting Started

**Phase Status:** ✅ Complete  
**Modules Covered:** Module 1, Module 2  
**Dataset:** Superstore Sales (Single Excel Source — Orders, Returns, People sheets)

---

## Phase Overview

Phase 1 establishes the foundation of the entire learning journey. Before any data modeling, DAX, or dashboard work is possible, two things must be in place: a clear understanding of what Power BI is and how it fits into the analytics landscape, and the practical ability to connect it to a real data source correctly.

This phase uses the Superstore Sales dataset throughout — the same dataset carried across all subsequent phases — so the hands-on work here is directly relevant to everything that follows.

---

## Modules in This Phase

### Module 1 — What Is Power BI & Getting Started

An introduction to Power BI Desktop: what it is, how it compares to Excel, and how to navigate its three core views. Covers the standard Power BI workflow and includes a first hands-on data load using the Superstore Sales dataset.

**Key concepts:** Power BI vs Excel, Report / Table / Model views, the Connect → Transform → Model → Visualize → Share workflow.  
**Status:** ✅ Complete  
**Notes:** `Module-01-Introduction-to-PowerBI/Module01-Notes.pdf`

---

### Module 2 — Connecting to Data Sources

How Power BI connects to data sources and the correct process for loading data. Covers the critical distinction between Load and Transform Data, Import vs DirectQuery connection modes, and loading all three sheets of the Superstore dataset.

**Key concepts:** Get Data, Navigator, Transform Data vs Load, Import vs DirectQuery, common connection errors and fixes.  
**Status:** ✅ Complete  
**Notes:** `Module-02-Connecting-Data/Module02-Notes.pdf`
