## Phase Overview

Phase 3 covers data modeling — transforming the cleaned tables from Phase 2 into a structured, production-ready star schema. This is the foundation everything else in Power BI is built on. Correct relationships, cardinality, and filter direction here directly determine whether DAX calculations and visuals produce accurate results.

---

## Modules in This Phase

### Module 4 — Data Modeling-Star Schema, Relationships, Cardinality, Filter Direction

Covers the full data modeling process for the Superstore Sales dataset. The cleaned tables from Power Query are structured into a 7-table star schema with properly defined relationships.

**Key concepts:** Star schema design, fact vs dimension tables, relationships, cardinality, filter direction, composite keys, dedicated Date table.  
**Status:** ✅ Complete
