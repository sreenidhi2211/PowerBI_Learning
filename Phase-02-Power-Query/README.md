## Phase Overview

Phase 2 covers Power Query — Power BI's built-in ETL (Extract, Transform, Load) engine. Every data source passes through Power Query before it enters the data model. This phase focuses on cleaning, reshaping, and preparing the Superstore Sales dataset so it is model-ready.

## Modules in This Phase

### Module 3 — Data Transformation

Covers the full Power Query workflow — from opening the editor correctly to applying transformations and loading clean data into the model. All work is applied hands-on to the Superstore Sales dataset.
